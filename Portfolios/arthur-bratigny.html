01

Site vitrine & architecture

Conception et développement complet du site one-page en Next.js 16 App Router — sections Hero, Specs, Démo, Galerie, About, Commande, FAQ et Footer.

Choix techniques
Design system glassmorphique : Variables CSS globales (--bg, --ink, --accent, --glass-bg…) partagées sur l'ensemble du site et des portfolios.
Animations au scroll : Lenis (smooth scroll) + GSAP ScrollTrigger synchronisés via un provider React dédié.
Scaffold 3D : React Three Fiber + drei pour l'affichage du modèle GLB SolidWorks, avec fallback CSS/SVG pendant la phase de modélisation.
02

Tunnel de commande & back-end

Implémentation du panier et du flux de commande complet — de la sélection du produit jusqu'à l'email de confirmation.

Composants & API
CartDrawer : Drawer glassmorphique en 3 étapes (panier → récap → confirmation), état géré avec Zustand 5.
API orders : Route Next.js POST /api/orders, persistance SQLite via Prisma 7, génération d'identifiant CB-XXXXX-XXX.
Email de confirmation : Template React Email envoyé via Resend à chaque commande validée.
03

Système de portfolios d'équipe

Conception d'un système permettant à chaque membre de publier son portfolio sans toucher au code du site : il suffit de committer un fichier HTML dans le dossier Portfolios/ du dépôt.

Fonctionnement
Les fichiers HTML sont chargés dynamiquement depuis l'API GitHub sans étape de build supplémentaire.
Design system commun défini dans ce template pour garantir la cohérence visuelle entre tous les portfolios.
Page équipe du site (/equipe) liste et affiche chaque portfolio automatiquement.
04

Chatbot d'assistance

Intégration d'un assistant conversationnel accessible depuis le site pour répondre aux questions sur le produit et la commande.

Réalisation
Composant chat isolé dans components/chat/, découplé du reste de l'UI.
Contexte produit injecté dans le prompt pour des réponses adaptées à Coco Bonbons.
